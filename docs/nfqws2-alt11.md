# ALT11 для nfqws2

Стратегия `alt11_nfqws2_full` переносит девять профилей Flowseal ALT11 на
nfqws2 с Lua API 5. Целевая версия: zaprett 7.1 с nfqws2 v0.9.4.7.
Game Filter выключен: последние два профиля используют порт 12, как в
исходной конфигурации при выключенном Game Filter.

Исходники:

- [Flowseal ALT11](https://github.com/Flowseal/zapret-discord-youtube/blob/eb16c1419057e36b8a36fbe7c959483450e6ac8b/general%20%28ALT11%29.bat).
- [zapret2, версия Lua-библиотек](https://github.com/bol-van/zapret2/tree/32951c0f6a95fd8fe105ebb88a2e8bb2cefba7e7).
- [Стандартный HTTP-фейк nfqws1](https://github.com/bol-van/zapret/blob/c4d0b1990129dce2b28095277173ee0d7702d304/nfq/desync.c).

## Состав

Манифест стратегии объявляет все зависимости. `index.json` регистрирует
стратегию, три Lua-файла, шесть бинарных файлов и восемь списков.
Уже имеющийся `quic_initial_www_google_com` используется повторно: его
байты совпадают с исходным файлом ALT11.

Две штатные Lua-библиотеки скопированы из указанной версии zapret2 без
изменений. Отдельный `alt11_port.lua` вызывает их функции `fake` и
`multisplit`. Загрузка всех трёх файлов задаётся в начале стратегии.
Имена новых ресурсов имеют префикс `alt11_`.

Списки и остальные бинарные файлы взяты из указанной версии Flowseal.
Пользовательские списки пусты. `ipset-all` содержит исходную заглушку
`203.0.113.113/32`, поэтому эти профили не включают обработку всех адресов.
`alt11_http_default.bin` содержит полный стандартный HTTP-фейк, 263 байта.

## Перенос параметров

| Исходный ALT11 | nfqws2 |
| --- | --- |
| `fake,multisplit`, split-pos 1 | `fake`, затем `multisplit` с `pos=1`; нативный API возвращает Lua-индекс 2 |
| seqovl 681 / 664 | Перекрытие 681 / 664 байта с соответствующим исходным шаблоном |
| fooling ts | Сдвиг TCP timestamp на -600000 только у фейков |
| repeats 8 | Каждый TCP-фейк повторяется 8 раз; настоящие сегменты отправляются один раз |
| Google ip-id zero | Нулевой IPv4 ID у фейка и разделённых сегментов |
| UDP repeats 11 / 6 / 10 | QUIC / Discord-STUN / неизвестный игровой UDP |
| Game Filter cutoff n4 | `--out-range=-n3`, обработка первых трёх исходящих пакетов |

## Проверка

Порт с той же TCP/QUIC-логикой проверен пользователем на Android с KernelSU:
YouTube работает. Пакет для PR дополнительно проверен нативным парсером
nfqws2 v0.9.4.7 (`--dry-run`) и тестами с его настоящим C Lua API и LuaJIT.
Тесты проверяют маркеры, перекрытие, порядок фейков, timestamps, повторы,
HTTP, QUIC, Discord/STUN, неизвестные игровые пакеты и повторную сборку
TCP. Они перехватывают Lua-функцию отправки и не передают пакеты в сеть.

`tests/nfqws2-alt11/native_lua_check.c` — отдельная точка входа для этих
тестов. Её нужно собрать с исходниками `nfq2/*.c`, кроме `nfqws.c`,
`nfq2/crypto/*.c` и LuaJIT, с определением `LUAJIT`, опциями
`-ffunction-sections -fdata-sections -Wl,--gc-sections` и зависимостями
libmnl, zlib, libm, libdl. Исходники nfqws2 и его Lua API не изменяются;
точка входа инициализирует только Lua.

После сборки тесты запускаются из корня репозитория:

```sh
python3 tests/nfqws2-alt11/run_native_tests.py /path/to/native_lua_check
```
